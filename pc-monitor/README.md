# PC操作ログ監視ツール

自分が所有・管理するWindows PCの操作ログ(リソース状況・システムイベント・
アプリ利用履歴・主要フォルダのファイル操作)を記録し、NASなど任意の場所へ
定期的に同期して、別の端末からリモートで確認するためのツールです。

## 前提・注意事項

- **自分が所有・管理するPCで、そのPCを使う全員が監視されていることを承知している場合のみ**
  使ってください。他人が使うPCに無断でインストールする、あるいは本人に知られないよう
  意図的に隠すような使い方はしないでください。
- このツールは意図的に **隠蔽・偽装機能を持たせていません**。エージェントは
  `pythonw.exe`(コンソール画面を出さない実行方法)で動きますが、プロセス名や
  タスクスケジューラへの登録名(`PCMonitorAgent` / `PCMonitorUploader`)はそのままで、
  タスクマネージャーやタスクスケジューラから普通に確認・停止できます。
- キーストローク(打鍵内容)やスクリーンショット、通信内容の記録は行いません。

## 記録する内容

| 種別 | 内容 | 既定の間隔 |
|---|---|---|
| resource | CPU/メモリ/ディスク使用率 | 2分ごと |
| window | アクティブウィンドウ(アプリ名・タイトル・利用時間) | 変化があったときのみ(10秒間隔で確認) |
| logon/logoff/lock/unlock/sleep/resume 等 | ログイン・ロック・スリープ・復帰などのシステムイベント | 発生時のみ(ポーリングなし) |
| file | 指定フォルダ(既定: ドキュメント・デスクトップ・ダウンロード)のファイル作成・変更・削除・移動 | 発生時のみ |

## 対象PCへの負荷について(重要)

常駐監視ツールである以上、CPU・メモリ・ディスクIOへの影響はゼロにはできません。
このツールでは以下の対策を入れて、負荷を最小限に抑えることを優先しています。

- ログはメモリにためて15秒ごと(または50件ごと)にまとめて書き込み、
  イベントのたびにファイルを開閉しない
- CPU使用率の取得をノンブロッキング化(1秒間の待機処理をなくした)
- 監視間隔を控えめに設定(リソース2分、ウィンドウ10秒)
- エージェント自身のCPU/IO優先度を「通常以下」に下げ、他の操作を邪魔しない
- 古いログを自動削除し、ディスク圧迫を防ぐ(既定14日、`config.yaml`で変更可)
- NASへの同期は差分のみ転送するrobocopy `/MIR` を使用

それでも非力なPC(古いHDD搭載機など)では体感できる負荷が乗る可能性はあります。
特にディスク使用率が慢性的に高いPCへの導入は避けることをおすすめします。

## セットアップ手順

1. Python 3.9以降をインストールし、PATHに追加する
2. 依存パッケージをインストール
   ```
   pip install -r requirements.txt
   ```
3. `config.yaml` を編集する
   - `upload.destination` に同期先(NASのネットワークパスなど)を指定
   - 監視するフォルダや間隔を必要に応じて調整
4. 管理者権限のPowerShellで登録スクリプトを実行
   ```
   powershell -ExecutionPolicy Bypass -File scripts\install_task.ps1
   ```
   これで次回ログオン時からエージェントが自動起動し、30分ごとにログがNAS等へ同期されます。

停止したい場合は、同じく管理者権限で `scripts\uninstall_task.ps1` を実行してください。

## リモートでの確認方法

1. NAS等に同期されたログフォルダ(`.jsonl`ファイル)を、確認したい端末に取得する
2. その端末で以下を実行してHTMLレポートを生成する
   ```
   python viewer/report.py --logs <同期されたログフォルダ> --out report.html --days 7
   ```
3. 生成された `report.html` をブラウザで開くと、アプリ利用時間・システムイベント・
   ファイル操作履歴・リソース状況のサマリーが確認できます。
