:::question
債券は「安全な投資」と聞きます。でも、金利が上がると債券の値段が下がるとも聞きました。お金を貸しているだけなのに、なぜ値段が変わるのでしょうか。
:::

:::answer
債券は、国や会社にお金を貸して、決まった利息と元本を受け取る約束の証書です。満期まで持てば約束どおりの金額が戻るのが原則ですが、途中で売る場合は、そのときの金利と比べて値段が決まるため上下します。
:::

## 債券は「借用証書」
[[債券]]は、国や会社がお金を借りるときに発行する証書です。国が出すものを[[国債]]、会社が出すものを社債といいます。
買った人は、決められた日に利息（[[利率]]）を受け取り、満期の日に貸したお金（元本）を返してもらいます。
株は会社の持ち主になる投資でした（第20話）。債券はそれに対して、お金を貸す投資です。

## 株とのちがい
| | 株式 | 債券 |
|---|---|---|
| 立場 | 持ち主 | 貸し手 |
| 受け取るもの | 利益に応じて変わる | 原則あらかじめ決まっている |
| 値動き | 大きい | 比較的小さい |

持ち主は会社が大きく成長すれば大きく得をしますが、貸し手が受け取るのは約束の利息までです。その代わり、会社が苦しくなっても貸し手は持ち主より先に返済を受けられます。

## 債券のリスク
債券にもリスクがあります。
- **[[信用リスク]]**: 借りた側がお金を返せなくなるリスク。返せない心配が大きい相手ほど、高い利率を払わないとお金を借りられません。
- **金利リスク**: 上で見たように、途中で売るときに値下がりしているリスク。
- **インフレのリスク**: 受け取る金額が固定なので、物価が上がると実質的な価値が目減りします（第6話）。

利率が高い債券は、それだけ返してもらえない心配が大きいという意味でもあります（第15話）。

:::why
なぜ金利が上がると、手元の債券の値段は下がるのでしょうか。
たとえば、利率1%の債券を持っているとします。その後、世の中の金利が上がり、新しく出る債券の利率が2%になりました。
このとき、わざわざ1%の古い債券を同じ値段で買う人はいません。2%の新しい債券を買えば済むからです。古い債券を売るには、値段を下げて「安く買えるぶん、合計では2%と同じくらい得になる」水準まで調整するしかありません。
逆に金利が下がれば、高い利率の古い債券は人気が出て値上がりします。債券の値段と金利がシーソーのように逆に動くのは、新しい債券との「比べっこ」で値段が決まるからです。
満期が先の債券ほど、低い利率に縛られる期間が長いので、値下がりの幅も大きくなります。
:::

:::student
日本の個人向け国債（例）は、1万円から買えます。たとえば「変動10年」は、半年ごとに利率が見直され、最低でも年0.05%が保証されています。発行から1年たてば、国に買い取ってもらう形で途中換金もできます（直前2回分の利息に相当する金額〈税引後〉が差し引かれます）。なお財務省は、2026年12月募集分から名称を「個人向け国債プラス」に変える予定としています。
20万円のうち5万円を「守るお金」として置く先の候補の一つになります。ただし、増やす力は株式より小さいことも理解しておきましょう。
:::

:::caution
「債券は元本保証」ではありません。発行した国や会社が返せなくなれば損をします。また外国の債券は、為替の動きで円に換えたときの金額が変わります（第41話）。
:::

:::summary
- 債券はお金を貸して、利息と元本を受け取る約束の証書
- 金利が上がると、手元の債券の値段は下がる（新しい債券との比べっこ）
- 高い利率は、返してもらえない心配の裏返しでもある
:::

:::quiz
Q: 利率1%の債券を持っています。世の中の金利が上がり、新しい債券の利率が3%になりました。持っている債券の値段はどうなりやすいですか。
- 上がる
- *下がる
- 満期まで変わらない
A: 3%の新しい債券があるのに、1%の債券を同じ値段で買う人はいません。値段を下げないと売れなくなります。
:::
