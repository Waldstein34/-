# 投資の「なぜ」がわかる本

大学1年生・投資完全初心者向けの入門書です。全50話・1話3〜5分。電車内などの隙間時間にスマホで読む前提で作っています。

## 読み方
- **Web版**: `dist/index.html` をスマホのブラウザで開く（1ファイルでオフラインでも動きます）。
  目次・既読管理・続きから読む・しおり・文字サイズ・ダークモード・クイズ・用語集・検索付き。
- **PDF版**: `dist/投資のなぜがわかる本.pdf`（A5、286ページ）。

## 学習プラン
1日1話で約7週間。詳しくは第1話「この本の歩き方」。

## 注意
- 制度・数字は2026年10月時点の情報です。NISA・iDeCo・税制・年収の壁などは改正されることがあるため、
  実際に手続きするときは金融庁・国税庁などの公式サイトで最新情報を確認してください。
- 制作環境の制約で、一部の公的サイトは検索結果の抜粋で確認しています（詳細は `REVIEW-NOTES.md`）。
- 特定の金融商品・金融機関をすすめるものではありません。

## 作り直し方
```
node build/build.mjs   # content/*.md → dist/index.html
node build/pdf.cjs     # dist/index.html → PDF
```
原稿の書式は `SPEC.md` を参照。
