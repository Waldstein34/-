# 投資の「なぜ」がわかる本 — 制作仕様書

## 読者像（全員必読）
- 大学1年生（18〜19歳）。投資は完全な初心者。手元資産は約20万円。アルバイトはこれから始めたい。
- 細かいところまで気になる性格。「そういうものだから」では納得しない。**根源的な理由（なぜそうなるのか）**を知りたい。
- 電車内などの隙間時間に、スマホで1話3〜5分で読む。
- 主目的は長期の資産形成。ただし仕組みの理解や個別株の入口も知りたい。

## 文体
- です・ます調。落ち着いた丁寧な口調。**「！」（全角・半角とも）は一切使わない**。
- 煽らない。「絶対」「必ず儲かる」などの断定は禁止。リスクは正直に書く。
- 専門用語は初出時にかならず一言で説明する。
- 1文は短め（目安60字以内）。スマホで読みやすいよう段落は2〜4文。
- 特定の金融機関・個別銘柄を推奨しない（例示する場合は「例」と明記し、複数を並べる）。

## 正確性
- 2026年10月時点の日本の制度に基づく。制度の数字（NISA枠、税率、iDeCo、扶養・年収の壁など）は
  **必ずWebSearch/WebFetchで金融庁・国税庁・厚生労働省・iDeCo公式などの一次情報を確認**してから書く。
- 改正予定・不確実な点は「2026年10月時点」「〜の予定」と明記する。
- 確認した出典は各話の末尾 `:::source` ブロックに記載する（URLと機関名）。
- 過去の市場データ（暴落率など）も可能な範囲で確認し、概数であることを示す（「約」）。

## 1話の構成（この順番・この記法を厳守）
ファイル名: `content/NN.md`（NNは2桁の話番号。例 `07.md`）

```
---
no: 7
part: 1
title: 金利とは何か
subtitle: なぜお金を貸すと「お礼」がもらえるのか
minutes: 4
---

:::question
今日の疑問を1〜2文で。読者の素朴な問いとして書く。
:::

:::answer
結論を1〜3文で先に言う。
:::

## 見出し
本文（Markdown）。見出しは `##` と `###` のみ。

:::why
「なぜ？」をもう一段掘る、根っこの理由。この本の核。各話に最低1つ。
:::

:::student
大学1年生・20万円の場合の具体例（数字を使う）。
:::

:::caution
注意点・よくある誤解（必要なときだけ）。
:::

:::summary
- まとめ1
- まとめ2
- まとめ3
:::

:::quiz
Q: 問題文
- 選択肢A
- *正解の選択肢（先頭に*）
- 選択肢C
A: 解説（1〜2文）
:::

:::source
- 機関名「ページ名」 URL
:::
```

### 使える記法
- `**太字**`、`- 箇条書き`、`1. 番号付き`、表（`| a | b |` 形式、3列以内・スマホで横スクロールしない幅に）
- 用語: `[[NISA]]` と書くと用語集にリンクされる。用語集に載せたい語は各話の末尾ではなく、
  担当範囲ごとの `content/glossary-<担当>.md` に `- 用語: 説明（1〜2文）` の形で書く。
- 数式は使わず、文章と簡単な計算例で説明する（例: 20万円 × 1.05 = 21万円）。
- 図が必要な場合は `:::figure` ブロックに簡単な説明を書く（実装側で表や図にする）。乱用しない。

### 分量
- 1話あたり本文 1,200〜2,000字（3〜5分）。長くなりそうなら要点を絞る。
